summary

1. 人群定位与漏斗：尚界拥有三大人群：A群(生活品质)和B群(家庭需求)是「窄而深」的高意向基本盘(100%男性，1-3岁幼儿家庭，看重生态，看车比价期)；C群(30-50w SUV泛意向)是「宽而浅」的破圈增量池(6成女性，高消费，BBA心智)。策略定调：A/B群打转化与硬核实测，C群打认知与品质破圈。

2. 竞品格局与红利机会：家庭侧主战场是问界M7(体量大但NPS环比大跌)与乐道L90；品质侧主战场是蔚来ES8与BBA。重大机会：BBA在小红书的「内容货架」极度空虚，品质平权的话题存在巨大的卡位空白！

3. 内容风向与窗口：30万级SUV赛道热度在高位震荡，未来必须主动造词造风；BBA内容货架空虚带来的「品质平权」卡位空窗期，是尚界低成本抢占高消品质人群的明确机会。

4. 场景选题矩阵：提炼出五大核心场景：① 幼儿家庭的安全出行 ② 高线通勤+鸿蒙智舱 ③ 周末短逃离与露营外放电 ④ 换购期硬核比价 ⑤ 越级品质的社交表达。配套达人组合与节奏打法。

1.1 合集内的份额结构

90 天内竞品集的搜索大盘中：

对尚界的含义：头部两个心智锚一个来自 BBA、一个来自新势力，品质人群的注意力天然分散在「豪华基线」与「新势力新车」两端，尚界的定位话术需要同时回应这两端。

1.2 内容供给与流量

两个核心结论：

① 家庭 SUV 新车赛道的内容供给并不拥挤——除问界 M7外，新能源竞品的 90 天新发笔记均在 2,000 篇以下，而需求端（搜索）并未同步收缩；

② BBA 的内容货架接近真空——奔驰 GLC 近 90 天新发笔记为 0、奥迪 Q5L 仅 33 篇、宝马 X3 1,165 篇，品质人群的搜索需求（GLC 419.2 万）与内容供给严重错配。对尚界的含义：围绕新车名、对比词与「品质平权」话题的内容存在明确卡位空间，尤其在 BBA 对话场里几乎没有新鲜的国产竞品内容在竞争。

2.1 三大人群一句话概览

A · 生活品质主导

「31-40 岁高消费已婚男性奶爸」。男性占 100%，31-40 岁合计 76.8%，已婚 67.9%，高消费 TGI 158；孩子 13-24 月龄 TGI 高达 209。品牌偏好几乎全是新能源头部：理想 TGI 1399、鸿蒙智行 1376、问界 1290、蔚来 1275。生活方式标签「质感男士」TGI 3149，是典型的高线城市品质家庭决策者。

B · 家庭需求主导

「26-40 岁家庭导向男性，鸿蒙智行铁杆」。男性占 100%，26-35 岁合计 74.4%；鸿蒙智行 TGI 2133、问界 1867，为三群中最高。孩子 0-3 月龄 TGI 118、13-24 月龄 TGI 241，孕育与新生儿浓度更前置。内容侧「看车选买」TGI 1447，处于活跃比车决策期。

C · 30-50w SUV I+TI

「23-35 岁高消费力泛兴趣人群，女性占 6 成」。女性 62.7%，26-30 岁 TGI 166 为主力；苹果用户占 53.7%（TGI 138），单笔 1000-3000 元消费 TGI 162。品牌偏好横跨宝马 / 奥迪 / 保时捷 / 爱马仕 / 携程，内容偏娱乐、影视、理财、买房——是待转化的「兴趣 + 浅意向」增量池。

结构判断：A、B 两个人群是「窄而深」的高意向核心盘（男性、家庭、新能源品牌心智已成型），C 是「宽而浅」的破圈蓄水池（性别均衡、消费力强但汽车浓度低）。上市期打法应为：A/B 打转化与口碑，C 打认知与破圈。

2.2 基础属性对比

年龄结构。A 群高度集中在 31-40 岁（31-35 岁约 45%、36-40 岁约 32%）；B 群以 26-30 岁为峰值（约 41%），31-40 岁次之；C 群 26-30 岁约 27%，19-25 岁仍保留约 27% 的年轻占比，年龄结构最分散。（分箱读图估算，仅作结构参考）

城市等级。三群都压在高线城市，A 与 B 的一线 + 新一线合计分别为 52.2% 与 51.9%，C 群 43.6% 且下沉到三至五线的比例更高。

2.3 消费特征与品牌偏好

消费力。A 群高消费占比 34.6%（TGI 158）；B 群高消费占比 31.2%（TGI 143）；C 群单笔千元级消费偏好 TGI 162，苹果用户占比 53.7%（TGI 138）。

汽车品牌偏好。A/B 两群的品牌偏好榜单几乎就是「新能源头部品牌图鉴」——理想、问界、鸿蒙智行、蔚来、极氪、方程豹 TGI 全部破千，其中 B 群对鸿蒙智行 TGI 高达 2133，与尚界的华为鸿蒙渠道心智高度同源，是最容易转化的心智通路。C 群则是 BBA + 保时捷 + 特斯拉的「豪华油电混合心智」（宝马 TGI 442、奥迪 442、保时捷 397），同时出现爱马仕、携程、胖东来等品质生活品牌——对尚界而言，C 群的沟通重点不是参数，而是「30-50w 价位段的品质感与科技感平替 / 升级」。

2.5 生活方式人群标签（二十大人群）

三群共同的高 TGI 标签是「自我超越者、未来原住民、自由畅行、自在户外、户外欢聚团、野趣探索家」——指向进取型、科技感、爱出行的共同底色。

差异在于：

A 群「质感男士 TGI 3149 + 高消耗中年 1756」，是品质消费与家庭责任并重的中坚；

B 群「筑巢青年 TGI 313」出现，家庭组建期特征更明显；

C 群独有「短逃离自愈派 TGI 486、寻乐运动派 429、心灵远行客 424」，周末短途逃离、运动、疗愈旅行是打动他们的场景钩子。

2.7 用车场景与需求 / 痛点推导（5 大场景）

场景 1｜幼儿家庭的安全出行（覆盖 A/B/C 三群）

数据依据：三群「13-24 月龄孩子」TGI 163-241，C 群「0-3 月」TGI 150、备孕 TGI 125。

典型画面：周末带娃去商场 / 公园 / 早教，安全座椅 + 婴儿车 + 全家装备一次性装下；老人同行需要舒适上下车。

需求 / 痛点：后排空间与平整度、儿童安全锁与座椅接口、车内环保材质与空气净化、后备箱装载力；痛点是「SUV 看着大、实际放不下婴儿车 + 露营装备」。

场景 2｜高线城市通勤 + 智能座舱生态（A/B 群为主）

数据依据：A/B 群一线 + 新一线占比约 52%，华为手机 TGI 128-132，鸿蒙智行品牌 TGI 1376 / 2133，科技数码-手机类目 TGI 402。

典型画面：北京 / 上海 / 杭州早晚高峰通勤，手机导航无缝流转车机，午休在车里开空调小憩。

需求 / 痛点：手车互联流畅度、智驾在拥堵路况的可用性、通勤能耗成本；痛点是「车机卡顿、生态割裂」，鸿蒙同源生态是尚界的天然解法。

场景 3｜周末户外 · 露营垂钓 · 短逃离（三群共有，C 群尤甚）

数据依据：「户外欢聚团」TGI 594-1220、「野趣探索家」643-1410、「自在户外」444-476；A 群关键词垂钓 TGI 843、机车 1110；C 群「短逃离自愈派 TGI 486、骑车 352」。

典型画面：周六驱车 1-2 小时去营地 / 湖边，车顶箱 + 装备，外放电煮咖啡；C 群女生则是骑行 / 飞盘 / 山系穿搭打卡。

需求 / 痛点：外放电功率、通过性与续航（郊野充电桩少）、装备收纳；痛点是「电车露营续航焦虑」，需强调真实续航与补能网络。

场景 4｜换购 / 增购决策期的横向比价（A/B 群核心）

数据依据：「看车选买-车型展示」TGI 1294-1364；搜索词几乎全是竞品新车名（理想 i9、极氪 8X、小鹏 G9L、智界 RX 等）；二手车 TGI 1357-1480、提车 TGI 1100-1576。

典型画面：家里已有一台油车 / 旧电车，二胎或品质升级驱动换购，晚上刷评测、周末带家人试乘试驾。

需求 / 痛点：与理想 / 问界 / 极氪的差异化对比、置换补贴、残值预期；痛点是「比花了眼、怕买贵怕背刺」，需要透明的价格权益与横评内容。

场景 5｜品质社交与形象表达（C 群为主）

数据依据：C 群品牌偏好含宝马 TGI 442、奥迪 442、保时捷 397、爱马仕 238；关键词投资 365、理财 335、买房 291；质感男士 TGI 653。

典型画面：26-35 岁高消费力人群，车既是通勤工具也是社交名片，关注品牌调性、设计感与科技标签。

需求 / 痛点：设计颜值、品牌故事、智能化带来的「谈资」；痛点是「新品牌信任度不足」，需要用鸿蒙 / 上汽背书 + 高端场景内容建立品牌质感。

2.8 上市种草策略

核心人群洞察摘要。尚界本次的主力人群可以概括为「一批正在换购窗口期的科技奶爸 + 一个高消费力的品质破圈池」：A/B 两群是 26-40 岁、集中在北上杭深的男性家庭用户，孩子多在 1-3 岁，华为 / 鸿蒙生态浓度高，品牌偏好榜单就是新能源头部图鉴（鸿蒙智行 TGI 最高 2133），搜索词全部指向竞品新车——他们不缺购车意愿，缺的是选择尚界的理由。C 群则是以 26-30 岁女性为主的高消费泛兴趣人群（苹果用户 53.7%、千元级消费 TGI 162），汽车浓度低但品质生活浓度高，是新车转化蓄水层。

内容方向建议（5 个选题方向）。

  1. 「奶爸实测」硬核横评：A/B 群「看车选买-车型展示」TGI 高达 1294-1364，直接对标理想 i9 / 极氪 8X / 小鹏 G9L 做空间、智驾、续航实测对比，回应搜索热词；
  2. 「1-3 岁娃家庭的第一台电车」：三群孩子 13-24 月龄 TGI 163-241，围绕安全座椅、后排平整度、环保座舱做场景内容；
  3. 「鸿蒙生态手车互联」科技体验：华为手机 TGI 128-132、鸿蒙智行 TGI 1376-2133，用「手机即车机」的流畅体验做差异化记忆点；
  4. 「周末逃离计划」户外场景剧：户外欢聚团 TGI 最高 1220、C 群短逃离自愈派 TGI 486，露营 + 外放电 + 垂钓内容同时覆盖 A/B 转化与 C 破圈；
  5. 「置换攻略 + 残值透明化」：二手车关键词 TGI 1357-1480，用置换权益、保值承诺打消决策顾虑。

乐道 L90 处于新车上升期：NPS 全场最高，7 月搜索量较 6 月下旬放大约 3.5 倍，是当前该人群注意力增长最快的车型；但其 90 天搜索体量只有问界 M7 的三分之一。

领克 900 量级最小但口碑最稳：搜索垫底，NPS 最高，属于「小而精」的对手，内容上打口碑牌而非声量牌。

蔚来 ES8 是当前声量与内容消费的双料头部：搜索 、阅读 均是全表第一档，放量效应明显

问界 M8 是口碑最稳的新能源对手：NPS 中上且环比为正，搜索与阅读体量稳定在第二梯队。

BBA 仍是品质人群的默认心智锚：奔驰 GLC 搜索位列全表第一，NPS 较高且环比 仍在上升；奥迪 Q5L 的 NPS 最高（油车口碑基线显著高于新能源阵营）。对 C 群「品质平权」的沟通，实质是从这三个心智锚里分流量。

  • 正面主战场是问界 M7：量级最大、口碑走弱，尚界上市期内容应直接回应 M7 用户的比较需求（空间、智驾、鸿蒙同源）；
